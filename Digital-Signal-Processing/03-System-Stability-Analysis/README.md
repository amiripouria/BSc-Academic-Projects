# Digital Signal Processing - System Stability Analysis

**Authors:** Pouria Amiri

This repository contains the MATLAB simulations, source code, and technical report for Laboratory 4 of the Digital Signal Processing (DSP) course. The project focuses on Z-transforms, filter gain analysis, and system stability.

## Project Structure
- `/src` : Contains all MATLAB scripts (`.m` files).
- `/report` : Contains the LaTeX source code and the generated PDF report.
- `/images` : High-resolution exports of the MATLAB plots.

## Topics Covered
1. **Z-Transform Analysis:** Plotting poles and zeros using `zplane` and `tf2zp`.
2. **Filter Properties:** Analyzing discrete-time filter amplitudes using `stem` plots.
3. **Frequency Response:** Calculating and plotting the gain of a highpass filter in decibels (dB).
4. **System Stability:** Evaluating stability by analyzing pole locations relative to the unit circle.

## Tools & Technologies
- **MATLAB:** For numerical simulations and plotting.
- **LaTeX:** For typesetting the technical report.
